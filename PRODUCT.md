# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Vite + React + TypeScript + Tailwind v4 (2026-10-28). Moved from static HTML so the real 21st.dev "Perspective Tunnel Hero" (React + framer-motion) could be used. Run with `npm run dev`; `npm run build` outputs static files in `dist/`.

## Users
Stony Brook University students on campus looking for a cheap, good cut close to where they live. They find the barber by word of mouth, a flyer or Instagram, check the work, then reach out.

## Product Purpose
Personal site for Busted Blends, a student barber cutting out of the dorms. Success = a visitor sees the work and contacts the barber.

## Positioning
A student cutting students, on campus: no shop trip, cuts in the styles students actually want (textured crops, taper/drop fades, two-block, mullet/wolf).

## Capabilities and Constraints
- Contact by phone, email and Instagram. Real values not yet given: placeholders live in one place and must be swapped before launch.
- No prices on the site (user decision).
- No booking system.

## Brand Commitments
- Name: Busted Blends.
- Colors: red and black (user-pinned).
